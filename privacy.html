1. Identificação e Escopo / Scope & Private Internal Use

O aplicativo Acervos do Saber Studio é uma ferramenta desktop de linha de comando (CLI) executada exclusivamente na estação local do criador e proprietário Gabriel Henrique P. de Paula para gerenciar o canal oficial Acervos do Saber (https://www.youtube.com/@AcervosdoSaber, ID do Canal: UCOdP1_uHZk_HqcCJUZ2Y4qw).

A aplicação não é comercializada, não possui acesso público para terceiros, não oferece criação de contas externas e não atende usuários finais fora da conta do próprio titular do canal.

2. Serviços de API do YouTube / YouTube API Services Disclosure

Esta aplicação utiliza oficialmente os Serviços de API do YouTube (YouTube API Services) — especificamente a YouTube Data API v3 e a YouTube Analytics API — para operar fluxos internos do próprio canal. Ao utilizar estes serviços, o aplicativo vincula-se aos seguintes documentos oficiais do Google e do YouTube:

  • Política de Privacidade do Google / Google Privacy Policy: https://policies.google.com/privacy
  • Termos de Serviço do YouTube / YouTube Terms of Service: https://www.youtube.com/t/terms

3. Dados Acessados e Finalidade / Accessed Data & OAuth 2.0 Scopes

O acesso autenticado via OAuth 2.0 solicita exclusivamente os quatro escopos estritamente necessários à operação do canal próprio:

  • https://www.googleapis.com/auth/youtube.upload — Envio resumível de vídeos originais produzidos pelo proprietário e agendamento de publicação no canal Acervos do Saber.
  • https://www.googleapis.com/auth/youtube.readonly — Leitura de informações do próprio canal autorizado, vídeos enviados, metadados públicos para pesquisa editorial e validação de cota/conexão.
  • https://www.googleapis.com/auth/yt-analytics.readonly — Consulta a métricas agregadas de visualizações, tempo de exibição, retenção e inscritos ganhos pelos vídeos do próprio canal para melhoria editorial.
  • https://www.googleapis.com/auth/youtube.force-ssl — Definição de miniaturas personalizadas (thumbnails), banner/marca d'água do próprio canal, atualização de título/agendamento e publicação de respostas a comentários após revisão e aprovação humana obrigatória do proprietário.

4. Armazenamento, Compartilhamento e Segurança / Storage, Sharing & Security

  • Armazenamento estritamente local: Tokens OAuth 2.0 (_antares/conexao/token.json), logs operacionais e relatórios analíticos são gravados apenas no computador local do proprietário, em pasta isolada e bloqueada por .gitignore para nunca serem enviados a repositórios públicos.
  • Zero compartilhamento ou venda: Nenhum dado obtido via API do YouTube é vendido, alugado, transferido ou compartilhado com terceiros, corretores de dados ou servidores externos.
  • Sem cookies ou rastreadores web: Estas páginas informativas estáticas hospedadas no GitHub Pages não coletam dados pessoais, não utilizam cookies nem scripts de rastreamento ou publicidade.

5. Retenção, Exclusão de Dados e Revogação de Acesso / Retention, Deletion & Revocation

Quaisquer dados autorizados obtidos pelos Serviços de API do YouTube mantidos localmente em arquivos de trabalho ou relatórios são atualizados periodicamente ou excluídos definitivamente em no máximo 30 dias (ou imediatamente quando o proprietário desejar encerrar o uso ou apagar os registros).

O usuário/proprietário pode revogar a qualquer momento o acesso concedido ao Acervos do Saber Studio diretamente na página de Configurações de Segurança do Google:

  • Revogar permissões OAuth no Google: https://myaccount.google.com/permissions
  • Após a revogação, basta remover o diretório local _antares/conexao/ e os arquivos locais de cache para eliminar imediatamente todos os tokens e dados armazenados no computador.
